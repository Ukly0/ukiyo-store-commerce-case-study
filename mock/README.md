# Interface mock

This folder contains a static, synthetic interface study for the Ukiyo Store commerce case study. It is not the original storefront and it is not connected to any backend.

Label used on every page:

> Interface mock — synthetic data; not a screenshot of the original store.

## Pages

- `catalog.html`: catalogue, filters and product cards.
- `product.html`: product detail, variant controls and a mock add-to-cart action.
- `cart.html`: line items, totals and a disabled checkout button.

## Properties

- Fictional label `NORTHLINE`; no original brand, logo, product photography or customer content.
- Original geometric SVG artwork in `assets/`.
- No external fonts, scripts, images or network calls.
- No payment, email, database or analytics integration.
- The checkout button is disabled.
- The mock does not claim fidelity to the historical store interface.

## Open locally

Open `catalog.html` directly in a browser, or serve the folder with any static file server. No build step is required.

## Screenshots

The images in `../docs/images/` were captured from these local pages with the available Playwright browser. They are mock captures, not evidence of the original store.
